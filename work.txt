Phase 1 — Dataset Construction (Weeks 1-3)
Taxonomy (Cialdini-based, defensible in a paper):
* Urgency/Scarcity ("act now, limited time")
* Authority impersonation ("this is your bank/the police")
* Isolation ("don't tell anyone, keep this between us")
* Reciprocity/Trust-building ("I helped you, now...")
* Emotional manipulation (fear, guilt, romance)
* Neutral/benign (control class)
Generation approach:
1. Use an LLM (via API) to generate ~150-200 multi-turn synthetic dialogues per tactic category, with system prompts specifying scam type (romance, tech support, phishing call, fake authority) — explicitly framed as safety research so the LLM cooperates.
2. Turn-level labeling: each conversational turn gets a tactic label (multi-label — a turn can carry more than one tactic).
3. Add a "benign conversation" class from public dialogue datasets (e.g., DailyDialog) as negative examples.
4. Manual spot-check ~10% for quality/realism — note this as a limitation in the paper (synthetic data caveat).
Output: ~1,000-1,500 labeled turns, JSON format: {conversation_id, turn_id, speaker, text, tactics: [...]}

Phase 2 — Model (Weeks 3-6)
* Base model: DistilBERT (you already have experience here) fine-tuned for multi-label sequence classification per turn.
* Context handling: Feed each turn concatenated with 1-2 prior turns (sliding window) so the model has conversational context, not just isolated sentences.
* Explainability: Integrate SHAP or Captum for token-level attribution — highlight which words triggered each tactic label.
* Training: Standard fine-tuning, 80/10/10 split, track F1 per tactic class (expect class imbalance — use weighted loss).
